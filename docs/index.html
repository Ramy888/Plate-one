Plate One

Tell it what is on your plate.
It names the one thing to add.

Plate One is a voice agent for the smallest useful nutrition question: what would make this meal more satisfying? Not what to cut out, not how many calories are in it, not what you should have eaten instead.

In progress. The engine, the catalogue, the photo path and the server are built and tested. The spoken conversation described below is what is being built next — this page says so rather than waiting to be true.

How it works

Say what you are eating. Rough is fine — “rice and some chicken”. The agent asks about anything it could not place, works out whether the meal is light on protein, fibre or healthy fat, and names one practical addition: a boiled egg, a scoop of hummus, a side salad. Then it tells you why.

Afterwards it asks one question: still hungry, comfortably satisfied, or too full? That single answer is the only thing it learns from.

The model runs the conversation. It does not make the recommendation.

The AssemblyAI Voice Agent API delivers tool calls to the app over the same connection that carries the audio. So the recommendation engine — a few hundred lines of deterministic code with no network access — runs on your own device, registered as the agent’s tools.

The model decides when to ask a question and how to say the answer. It never decides what to recommend. The same plate always gives the same suggestion, and you can read the rule that produced it.

A language model asked for nutrition advice will invent some — confidently, fluently, differently each time. This one cannot. The only additions it can name are the ones the engine returned.

What it is not

Not a calorie tracker. Not a diet. Not a food diary. Not medical advice — see the terms.

Privacy

No account, no sign-in, no analytics, no ads. Your meals, your goal and your history stay on your device. The two things that cost money to run — photographing a meal and having a plate drawn — send one photo or one list of food names to be read or drawn, and then it is discarded. Read the full privacy policy, or see how to delete your data.

Open source
